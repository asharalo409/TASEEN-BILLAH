# মানবসেবা ফাউন্ডেশন (Manob Sheba Foundation) - পূর্ণাঙ্গ ওয়েব প্ল্যাটফর্ম

একটি আধুনিক, স্বচ্ছ, প্রিমিয়ার এবং স্বয়ংসম্পূর্ণ ফাউন্ডেশন ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন। এই প্রজেক্টটি GitHub-এ রেখে খুব সহজেই চালানো যায় এবং ব্যাকএন্ড ডাটাবেজ হিসেবে **Supabase (PostgreSQL)** ব্যবহার করার জন্য সম্পূর্ণ প্রস্তুত।

## 🌟 প্রধান প্রধান ফিচারসমূহ

1. **স্বচ্ছ পাবলিক অডিট ও আর্থিক খতিয়ান (100% Transparency):**
   - এ মাসের খরচ, আয়-ব্যয় ও উদ্বৃত্তের লাইভ হিসাব।
   - গত বছরের পূর্ণাঙ্গ ব্যালেন্স শিট এবং বাৎসরিক অডিট।
   - সকল সদস্যের যৌথ তালিকা: কে কত টাকা অনুদান দিয়েছে, কোন কোন মাসের ফি পরিশোধ করেছে, এবং মোট কতদিন উপস্থিত হয়েছে।
   - খাতভিত্তিক পৃথক তহবিল (বন্যা পুনর্বাসন, শীতবস্ত্র, শিক্ষা ও এতিম, চিকিৎসা)।
   - প্রতিটি খরচের অডিটকৃত ভাউচার ফটো ও অনুমোদনকারী কর্মকর্তার বিবরণ।

2. **ব্যক্তিগত সদস্য ড্যাশবোর্ড (Personal Member Dashboard):**
   - প্রতি সদস্যের জন্য পৃথক ড্যাশবোর্ড ও সিক্রেট লগইন কোড।
   - ব্যক্তিগত অনুদানের তালিকা ও ডিজিটাল রসিদ প্রিন্ট।
   - মাসিক চাঁদার হিসাব ও পরিশোধিত/বকেয়া খতিয়ান।
   - কাজের অগ্রগতি ও ফিল্ড রিপোর্ট আপডেট (ছবি/লিংকসহ)।
   - ডিজিটাল অফিসিয়াল আইডি কার্ড জেনারেটর ও প্রিন্ট সুবিধা।

3. **পদভিত্তিক কার্যকরী টুলকিট (Role-Based Workstations):**
   - **সভাপতি:** কেন্দ্রীয় রেজুলেশন প্রকাশ, জরুরি বাজেট ছাড় অনুমোদন ও নির্বাহী তদারকি।
   - **সাধারণ সম্পাদক:** সদস্য হাজিরা খাতা (Attendance marking), জরুরি সভার নোটিশ জারি ও ভলান্টিয়ার টিম লিডার নিয়োগ।
   - **কোষাধ্যক্ষ / কেসিয়ার:** দ্রুত খরচের ভাউচার এন্ট্রি, সদস্যদের মাসিক ফি গ্রহণ ও ক্যাশ রিকনসিলিয়েশন।
   - **ক্রীড়া ও সাংস্কৃতিক সম্পাদক:** যুব কল্যাণ টুর্নামেন্ট ও সাংস্কৃতিক ইভেন্ট প্ল্যানার।
   - **প্রচার ও প্রকাশনা সম্পাদক:** ফটো/ভিডিও ও প্রেস রিলিজ প্রকাশ।
   - **স্বাস্থ্য ও রক্তদান সমন্বয়ক:** জরুরি রক্তের রিকোয়েস্ট তৈরি ও রক্তদাতা ম্যাচিং।

4. **ইন্টারেক্টিভ রিলিফ লোকেশন ম্যাপ ও প্রমাণপত্র:**
   - কোথায় কত টাকা সাহায্য করা হয়েছে, কতজন উপকৃত হয়েছে তার ইন্টারঅ্যাকটিভ ম্যাপ ভিউ।
   - ফটো, ইউটিউব/ড্রাইভ ভিডিও ও ডকুমেন্ট প্রমাণ লিঙ্ক।

5. **লাইভ কমিউনিটি চ্যাট রুম ও ১-অন-১ প্রাইভেট চ্যাট:**
   - সকল সদস্যের যৌথ আলোচনা এবং ব্যক্তিগত নিরাপদ মেসেজিং।

6. **ঘড়ি ও ৩টি ক্যালেন্ডার উইজেট:**
   - লাইভ সময়, ইংরেজি ক্যালেন্ডার, বাংলা সন/বঙ্গাব্দ এবং ইসলামিক হিজরি ক্যালেন্ডার।

7. **ভার্চুয়াল মিটিং হাব:**
   - জুম (Zoom), গুগল মিট (Google Meet), ফেসবুক পেজ/গ্রুপ, হোয়াটসঅ্যাপ ও টেলিগ্রাম গ্রুপ সরাসরি কানেক্ট করার বাটন।

8. **অফিসিয়াল নোটিশ বোর্ড ও মাল্টিমিডিয়া গ্যালারি:**
   - জরুরি নোটিশ, লাইটবক্স গ্যালারি ও সোশ্যাল মিডিয়া শেয়ার বাটন (Facebook, WhatsApp, X, Telegram)।

## 🚀 GitHub ও Supabase দিয়ে চালানোর নিয়ম

### ধাপ ১: GitHub থেকে রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/your-username/manobsheba-foundation.git
cd manobsheba-foundation
```

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ধাপ ৩: Supabase ডাটাবেজ সেটআপ করুন
1. [Supabase](https://supabase.com)-এ একটি অ্যাকাউন্ট তৈরি করে নতুন প্রজেক্ট খুলুন।
2. Supabase ড্যাশবোর্ডের বাম পাশের মেনু থেকে **SQL Editor**-এ যান।
3. প্রজেক্টের রুট ডিরেক্টরিতে থাকা `supabase_schema.sql` ফাইলের পুরো কোডটি কপি করে SQL Editor-এ পেস্ট করে **Run** চাপুন।
4. সাথে সাথে আপনার ডাটাবেজে প্রয়োজনীয় সকল টেবিল (`members`, `donations`, `expenses`, `campaigns`, `fund_sectors`, `notices`, `blood_donors`, `chat_messages` ইত্যাদি) এবং সিকিউরিটি পলিসি স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে।

### ধাপ ৪: এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন
প্রজেক্টের রুটে `.env` নামে একটি ফাইল তৈরি করুন (বা `.env.example` কপি করুন):
```env
VITE_SUPABASE_URL="https://your-project-id.supabase.co"
VITE_SUPABASE_ANON_KEY="your-anon-public-api-key"
```
*(এই তথ্যগুলো পাবেন Supabase প্রজেক্টের `Project Settings` -> `API` সেকশনে)*

> **নোট:** Supabase সংযোগ না দিলেও অ্যাপ্লিকেশনটি লোকাল স্টোরেজ (LocalStorage) এবং অফলাইন ক্যাশিং দিয়ে সম্পূর্ণ কার্যকরভাবে কাজ করবে!

### ধাপ ৫: লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` অথবা কনসোলে দেখানো লিংকে প্রবেশ করুন।

### ধাপ ৬: প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
```
বিল্ড হওয়া `dist` ফোল্ডারটি Vercel, Netlify, Cloudflare Pages বা যেকোনো হোস্টিংয়ে সরাসরি ডেপ্লয় করা যাবে।
